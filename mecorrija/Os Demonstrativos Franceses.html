CE, CET, CETTE, CES e C'EST - Domine a elegância dos adjetivos demonstrativos

✨ Os Demonstrativos do Francês

1

"CE" - Masculino Singular 🌿

📚 Contexto e Significado

"CE" é o adjetivo demonstrativo masculino singular, equivalente a "este", "esse" ou "aquele" em português.

Uso: Antes de substantivos masculinos singulares que começam com consoante

Tradução: "este/esse" (masculino)

Francês Português
Ce livre est intéressant. Este livro é interessante.
Ce garçon est mon frère. Este menino é meu irmão.
Ce professeur est excellent. Este professor é excelente.
🔍 Anatomia da Expressão

💡 Dica rápida

Use "CE" antes de substantivos masculinos que começam com consoante

Parte Função Observação
Ce Demonstrativo masculino Equivale a "este/esse"
livre Substantivo masculino Começa com consoante

📝 Resumindo

CE = demonstrativo masculino singular

Usado antes de substantivos masculinos com consoante inicial

Equivale a "este/esse" em português

Forma básica dos demonstrativos franceses

"Ce moment est parfait."
"Este momento é perfeito."
2

"CET" - Masculino Especial 📜

🌿 Significado e Uso

"CET" é a forma especial do demonstrativo masculino singular, usada antes de substantivos que começam com vogal ou "H" mudo.

Uso: Antes de substantivos masculinos com vogal ou H mudo

Tradução: "este/esse" (masculino)

Francês Português
Cet arbre est grand. Esta árvore é grande.
Cet homme est gentil. Este homem é gentil.
Cet hôtel est cher. Este hotel é caro.
✨ Por que "CET" existe?

💡 Dica rápida

"CET" evita o encontro de vogais, facilitando a pronúncia

CE + arbre → "Ce arbre" ❌ (encontro de vogais)

CET + arbre → "Cet arbre" ✅ (pronúncia fluida)

Curiosidade fonética: O francês evita encontros de vogais (hiato) para manter a fluência da fala. "CET" serve como ponte fonética.

📝 Resumindo

CET = demonstrativo masculino especial

Usado antes de vogais e H mudo

Facilita a pronúncia evitando hiatos

Mesmo significado que "CE"

"Cet ami est très fidèle."
"Este amigo é muito fiel."
3

"CETTE" - Feminino Singular 💫

🌿 Contexto e Significado

"CETTE" é o adjetivo demonstrativo feminino singular, equivalente a "esta", "essa" ou "aquela" em português.

Uso: Antes de todos os substantivos femininos singulares

Tradução: "esta/essa" (feminino)

Francês Português
Cette femme est belle. Esta mulher é bonita.
Cette maison est grande. Esta casa é grande.
Cette idée est géniale. Esta ideia é genial.
🔍 Anatomia da Frase
Palavra Função Observação
Cette Demonstrativo feminino Usado com todos os femininos
femme Substantivo feminino Começa com consoante
idée Substantivo feminino Começa com vogal

📝 Resumindo

CETTE = demonstrativo feminino singular

Usado com todos os substantivos femininos

Não muda com vogais (diferente do masculino)

Equivale a "esta/essa" em português

"Cette histoire est émouvante."
"Esta história é emocionante."
4

"CES" - Plural 🎭

🌿 Contexto e Significado

"CES" é o adjetivo demonstrativo plural, usado para ambos os gêneros, equivalente a "estes/esses" ou "estas/essas" em português.

Uso: Antes de todos os substantivos no plural

Tradução: "estes/estas" ou "esses/essas"

Francês Português
Ces livres sont intéressants. Estes livros são interessantes.
Ces femmes sont belles. Estas mulheres são bonitas.
Ces arbres sont grands. Estas árvores são grandes.
🔍 Anatomia da Frase
Palavra Função Observação
Ces Demonstrativo plural Única forma para plural
livres Substantivo masculino plural Termina com -s
femmes Substantivo feminino plural Termina com -s

📝 Resumindo

CES = demonstrativo plural

Usado com todos os substantivos no plural

Não faz distinção de gênero no plural

Equivale a "estes/estas" em português

"Ces moments sont précieux."
"Estes momentos são preciosos."
5

"C'EST" - Este é 🌟

🌿 Significado e Contexto

"C'EST" é uma contração de "Cela est" (isto é), usada para apresentar ou identificar algo/s alguém.

Uso: Para apresentações e identificações

Tradução: "Isto é", "Este é", "Esta é"

Situação Exemplo Francês Tradução
Apresentação C'est mon ami. Este é meu amigo.
Identificação C'est un livre. Isto é um livro.
Opinião C'est magnifique! Isto é magnífico!
🔍 Anatomia da Expressão

💡 Dica rápida

"C'est" é uma expressão fixa muito comum no francês falado

Parte Função Observação
C' Contração de "Cela" Significa "isto"
est Verbo être Forma de "é"

📝 Resumindo

C'EST = "Isto é" / "Este é"

Contração de "Cela est"

Usado para apresentações e identificações

Expressão muito comum no francês falado

"C'est la vie!"
"Assim é a vida!"
6

Resumo Prático 🎭

🌿 Tabela de Referência Rápida

Resumo completo dos demonstrativos franceses para consulta rápida.

Demonstrativo Uso Exemplo Tradução
CE Masculino singular + consoante ce livre este livro
CET Masculino singular + vogal/H mudo cet arbre esta árvore
CETTE Feminino singular cette femme esta mulher
CES Plural (todos os gêneros) ces livres estes livros
C'EST Apresentação/identificação c'est mon ami este é meu amigo
🔍 Regra Mnemônica

📘 Dica de Memorização

Lembre-se: "CE antes de consoante, CET antes de vogal, CETTE para feminino, CES para plural"

Para praticar:

  • ___ homme (homem) → CET (vogal)
  • ___ femme (mulher) → CETTE (feminino)
  • ___ livre (livro) → CE (consoante)
  • ___ amis (amigos) → CES (plural)

📝 Resumindo

CE → masculino + consoante

CET → masculino + vogal/H mudo

CETTE → feminino singular

CES → plural (todos os gêneros)

C'EST → apresentações/identificações

"Ce jour, cet instant, cette émotion, ces souvenirs... c'est la vie!"
"Este dia, este instante, esta emoção, estas lembranças... isto é a vida!"
